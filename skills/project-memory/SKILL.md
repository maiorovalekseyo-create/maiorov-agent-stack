# Project Memory

Use these durable files:

## PROJECT.md
- goal;
- current state;
- fixed/approved behavior;
- current task;
- next 3–5 steps;
- known issues;
- important links;
- last verified state.

## DESIGN.md
- visual direction;
- approved references;
- typography;
- color/materials;
- layout/spacing;
- motion;
- imagery;
- desktop/mobile rules;
- what "WOW" means;
- forbidden drift.

## DECISIONS.md
For material decisions record:
- decision;
- why;
- alternatives rejected;
- trigger/condition to revisit.

Before material changes, read them.
After material changes, update only what actually changed.
Do not turn them into a diary.
